# 그 한 판, 게임이 아닙니다

법무부 제19기 저스티스 서포터스 **법PT** · 2026년 9월 청소년 온라인 도박 예방 캠페인

학교 게시 포스터의 QR로 연결되는 교육용 대화 시뮬레이션 페이지입니다.
친구의 권유 메시지에 어떻게 답할지 직접 고르며 게임과 도박의 경계를 확인합니다.

- 돈도 결제도 없는 교육용 콘텐츠입니다. 도박 화면이나 방식은 등장하지 않습니다.
- 로그인, 개인정보 입력이 없습니다.
- 인용 근거: 한국도박문제예방치유원 「2025년 청소년 도박 실태조사」, 형법 제246조, 게임산업진흥에 관한 법률 제32조·제33조, 국민체육진흥법 제26조·제48조
- 상담: 국번없이 1336 (한국도박문제예방치유원)
